Połączenie z repozytorium

Panel zapisuje zmiany bezpośrednio w plikach data/*.json repozytorium na GitHubie. Potrzebny jest Twój token GitHub (fine-grained, tylko to repozytorium, uprawnienie Contents: Read and write). Token zostaje wyłącznie w tej przeglądarce.
